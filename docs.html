Operational Governance & Analytics API

Operational layer endpoints providing real-time engine health metrics, shadow mode rule execution telemetry, and weekly 30-day production rule health evaluations.

Endpoints

GET /api/v1/analytics/engine-health

Retrieves 7-day rolling scan totals, recommendation distributions (BUY/SELL/HOLD), positive outcome rate, and average confidence scores.

GET /api/v1/analytics/shadow-status

Retrieves execution counts and latest timestamps for active watch-only shadow rules (news_dedup, sentiment_decay, market_breadth, sector_strength).

GET /api/v1/analytics/rule-governance

Retrieves 30-day rolling false-positive rates and health statuses (GREEN, YELLOW, RED, INSUFFICIENT_DATA) for all promoted production rules.

python -m app.governance.experiment_cli governance-report
